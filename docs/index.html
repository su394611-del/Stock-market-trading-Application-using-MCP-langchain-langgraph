Stock Market Trading Application Using MCP, LangChain and LangGraph

A Python-based educational project demonstrating AI-agent workflows, simulated stock market operations, and Model Context Protocol integration.

Project Features

  • LangChain tools and tool calling
  • LangGraph workflows and conditional routing
  • ReAct-style agent orchestration
  • Model Context Protocol (MCP) integration
  • STDIO MCP stock-market server
  • HTTP MCP news server
  • Simulated stock price lookup
  • Simulated stock buying and selling
  • Synthetic market news and sentiment
  • Optional OpenAI LLM integration
  • Python and Jupyter Notebook demonstrations

Architecture

The application demonstrates how LangChain tools, LangGraph execution graphs and MCP servers can work together.

Important Notice

This project is for educational purposes. It does not execute real brokerage trades. The example prices and market news are simulated or synthetic.
