03 / EXECUTION MODES

Study the flow offline, or connect a model.

API access is optional. The project is designed to let developers explore graph mechanics without sending requests to a commercial model by default.

Offline mode

DEFAULT

A deterministic rule-based object imitates the bind_tools, invoke and ainvoke interface. It is useful for learning tool-routing behavior without a paid API.

  • Predefined examples and rule-based parsing
  • Simulated stock quotes and trades
  • LangGraph control-flow exploration
  • No LLM inference or investment analysis

Optional live mode

API KEY REQUIRED

The --live option can call an OpenAI tool-capable model when properly configured. MCP examples can also connect to local tool servers.

  • Set OPENAI_API_KEY privately
  • Model usage may incur charges
  • Local MCP servers still return fictional data
  • Live integrations are not independently benchmarked

Five inspectable tool interfaces.

Environment & integration notes

Use a dedicated Python environment and inspect the source before connecting external APIs. Offline and live modes have different dependencies and verification requirements.

  • Python 3.12 is recommended in the repository README.
  • The example requires no CUDA GPU.
  • Use your own API key only for explicitly enabled live mode.
  • Do not commit API keys or private environment files.
  • The HTTP MCP example binds to localhost; do not expose it publicly.
  • In Jupyter, run asynchronous examples with await in notebook cells.

The repository README reports syntax and standard-library checks, but not complete end-to-end third-party integration validation. Package compatibility should be checked in your own environment.
